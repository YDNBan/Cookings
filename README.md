# 🏨 Cookings – Hotel Discovery App  

A simple hotel discovery web application that helps users find hotels in any city they search.  
The app fetches real-time data from the **Bookings API**, displays hotel details, and integrates with **Google Maps** for location visualization. 
Users can also filter results and quickly navigate to official hotel websites to make reservations.  

---

## ✨ Features  
- 🔍 **Hotel Search** – Find hotels by city name (powered by Bookings API).  
- 🏷️ **Filter Listings** – Sort by distance, price, and quality (ascending/descending).  
- 🗺️ **Interactive Map** – View hotel locations directly on Google Maps.  
- 📋 **Hotel Details** – See key info about each hotel.  
- 🔗 **Direct Reservation Link** – Redirect to the hotel’s official site for booking.  

---

## 🚀 Tech Stack  
- **Frontend:** React (with hooks & components)  
- **Backend:** Express.js + Node.js + Python for API script 
- **API Integration:** Bookings API  
- **Other Tools:** Google Maps API
